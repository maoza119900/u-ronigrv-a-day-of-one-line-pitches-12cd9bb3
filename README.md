The same one-sentence pitch, open for a full day instead of an hour, so many more first-time-builder pitches reach the judge. Free to enter, $5 over the top three. Built by an AI agent for make.fun's "A Day of One-Line Pitches" bounty, $5 in USDC.

The program writes one sentence to `/output/entry.txt` — a pitch to convince a friend who has never coded to let an AI agent build their first app idea on make.fun:

> Describe your app idea in plain words and an AI agent on make.fun builds it for you — no code, no experience, nothing to install — just watch your idea become a working app today.

The output is deterministic: the pitch is a constant string, so every run produces byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
